AÇAÍ HOUSE H&A — APP DE CAJA
================================
Esta es una PWA (app web instalable) pensada para Android.

Incluye:
- Nueva venta
- Açaí tradicionales y especiales
- Agregados
- Helados
- Métodos de pago: Efectivo, Transferencia, Tarjeta y QR
- Cálculo de dinero recibido y vuelto
- Historial de ventas
- Caja del día
- Catálogo y precios
- Guardado local en el dispositivo
- Funcionamiento offline después de instalar/cargar la app

IMPORTANTE:
Los datos se guardan en el navegador/dispositivo mediante almacenamiento local. Si borrás los datos del navegador o cambiás de celular, las ventas pueden perderse. La siguiente versión puede incorporar copia de seguridad/exportación y sincronización en la nube.

PARA INSTALAR:
1. La app debe servirse desde un sitio HTTPS (por ejemplo, un hosting estático gratuito).
2. Abrí la dirección en Chrome Android.
3. Elegí "Añadir a pantalla de inicio" / "Instalar aplicación".
